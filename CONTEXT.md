## 1. Repository Overview
- **Project:** LinguaVerve (`lingua-verve`) — *The Polyglot's Tactical Blueprint*
- **Runtime & Build:** Vite 6.0 (`base: './'`) + React 18.3 + TypeScript 5.7 + Tailwind CSS 3.4
- **Test Runner:** Vitest 3.0 + `@testing-library/react` + `jsdom`
- **Architecture:** Zero-backend, static-deployable Single-Page Application (SPA) with localStorage persistence (`linguaverve_theme`, `linguaverve_bookmarks`, `linguaverve_mastered`, `linguaverve_muted`) and a Web Audio API sound/TTS engine.

## 3. Reusable Helpers (Ponytail Rule: Reuse First)
- **Filtering & Search:** Always use `filterTips(options)` from `src/data/index.ts` instead of writing ad-hoc array filters in components.
- **Language & Level Lookups:** Use `getLanguage(id)`, `getActiveLanguages()`, and `getLevelDetail(level)` from `src/data/index.ts`.
- **UI Sound & Pronunciation:** Use `soundEngine.playClickSound()`, `soundEngine.playSuccessChime()`, and `soundEngine.speak(text, langCode)` from `src/utils/audio.ts`.
